# Periodic Table Database

Proyek ini dibuat untuk memenuhi tugas sertifikasi **Relational Database** dari **freeCodeCamp**.

## Isi Repositori
* `periodic_table.sql` — File *dump* database PostgreSQL (`periodic_table`) yang berisi tabel `elements`, `properties`, dan `types`.
* `element.sh` — Skrip Bash untuk mencari dan menampilkan informasi unsur kimia berdasarkan nomor atom, simbol, atau nama unsur.
